# Theme switch cost

Time for Mermaid to re-render the 14 valid diagrams after a theme or mode switch. Pele renders once and repaints from CSS variables, so its cost is zero renders.

| Theme | Mode | Mermaid re-render |
| --- | --- | --- |
| ember | light | 1232 ms |
| ember | dark | 792 ms |
| ash | light | 717 ms |
| ash | dark | 835 ms |
| slate | light | 708 ms |
| slate | dark | 777 ms |
